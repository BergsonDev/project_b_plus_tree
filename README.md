# project_b_tree
Projeto realizado para compreender a estrutura de dados em árvore, na qual escolhemos uma categoria/contexto de aplicação de um projeto de inserção, listagem, edição e remoção de informações através da estrutura de dados árvore b


## Comando de compilação 
`gcc $(pkg-config --cflags gtk4) -o crud_project *.c $(pkg-config --libs gtk4) -std=c11 -Wall -Wextra`
